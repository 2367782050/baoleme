# 验收测试清单

## 1. 通用验收

每个阶段必须通过：

- 类型检查。
- lint。
- 单元测试。
- 关键页面手动点击。
- 关键接口错误态测试。

推荐命令：

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

如果项目没有某个脚本，开发者必须补齐或说明替代命令。

## 2. 注册登录

用例：

- 新邮箱注册成功。
- 重复邮箱注册失败。
- 弱密码注册失败。
- 错误密码登录失败。
- 正确账号登录成功。
- 登录后 `/api/auth/me` 返回用户、会员、配额。
- 退出登录后受保护页面跳转登录页。

验收标准：

- 错误提示明确。
- 密码不明文存储。
- 普通用户不能访问后台。

## 3. 邀请与会员

用例：

- 使用邀请码注册后记录邀请人。
- 新用户获得默认会员。
- 会员过期后高价值能力不可用。
- 会员码兑换成功。
- 已使用会员码不能重复兑换。
- 配额使用后正确扣减。

验收标准：

- 所有高价值接口都检查配额。
- 配额不足返回 `QUOTA_EXCEEDED`。

## 4. 素材库

用例：

- 行业筛选。
- 关键词搜索。
- 平台筛选。
- 排序。
- 分页。
- 收藏账号。
- 收藏文章。
- 取消收藏。
- 导出素材。
- 从素材发起创作。

验收标准：

- 列表不会越权显示其他用户私有数据。
- 导出文件能打开。
- 导出扣减配额。
- 无数据时有空状态。

## 5. 提示词库

用例：

- 创建分组。
- 编辑分组。
- 删除分组。
- 创建提示词。
- 编辑提示词。
- 删除提示词。
- 使用文本素材生成提示词。
- 使用 URL 素材生成提示词。
- AI 失败时显示失败原因。

验收标准：

- 生成结果自动保存。
- 用户只能看到自己的提示词。
- 生成次数扣减。

## 6. 智能创作

用例：

- 创建文章分组。
- 选择提示词生成文章。
- 使用素材 URL 生成文章。
- 使用粘贴文本生成文章。
- 查询任务状态。
- 生成失败重试。
- 编辑文章。
- 删除文章。
- 状态筛选。

验收标准：

- 文章生成必须异步。
- 页面轮询状态。
- 失败原因可读。
- 成功后有 Markdown 内容。
- 配额扣减准确。

## 7. 一键排版

用例：

- 从智能创作进入排版。
- 手动输入 Markdown。
- 预览 HTML。
- 切换模板。
- 切换主题色。
- 修改字体、字号、行距、段距。
- 上传封面。
- 保存配置。
- 复制 HTML。

验收标准：

- 预览实时或半实时更新。
- 保存后刷新不丢失。
- HTML 粘贴到微信公众号编辑器时结构可用。
- 图片和段落不应出现明显错位。

## 8. 公众号 mock

用例：

- 创建 mock 公众号。
- 公众号数量超过套餐限制时失败。
- 从文章发起草稿推送。
- 查询推送任务。
- mock 推送失败时显示原因。

验收标准：

- 草稿推送接口通过 `WeChatDraftAdapter`。
- 不允许页面直接写死成功状态。

## 9. 支付与订单 mock

用例：

- 创建订单。
- mock 支付成功。
- 订单状态变为 paid。
- 用户会员生效。
- 重复支付不会重复开通。

验收标准：

- 订单号唯一。
- 支付状态流转可追踪。
- 订单支付后触发佣金计算。

## 10. 推广返佣

用例：

- 用户查看推广链接。
- 新用户通过邀请码注册。
- 被邀请用户支付后产生佣金。
- 佣金进入待结算或可提现状态。
- 用户提交提现。
- 管理员审核提现。

验收标准：

- 不能给自己邀请自己。
- 佣金金额计算准确。
- 提现状态不可随意越权修改。

## 11. 后台运营

用例：

- 管理员登录后台。
- 导入素材。
- 查看用户。
- 手动开通会员。
- 查看 AI 任务。
- 查看失败原因。
- 审核提现。

验收标准：

- 普通用户访问后台返回 403 或跳转。
- 导入失败有行级错误。
- 管理操作写入审计日志。

## 12. 安全验收

必须检查：

- 密码哈希。
- Session 安全。
- CSRF 或同等防护。
- API 鉴权。
- 管理员鉴权。
- 文件上传大小和类型限制。
- XSS 风险，尤其 Markdown 到 HTML。
- SSRF 风险，尤其 URL 素材抓取。
- AI prompt injection 防护。

## 13. UI 验收

原则：

- 工具型界面优先效率，不做营销式大 hero。
- 扁平化、清晰、低噪音。
- 表格、筛选、状态、按钮必须易扫描。
- 移动端至少能完成核心流程。

页面必须检查：

- 首页。
- 登录注册。
- 爆款素材。
- 提示词库。
- 智能创作。
- 一键排版。
- 公众号管理。
- 会员中心。
- 推广中心。
- 后台运营。

## 14. 上线前检查

上线前必须确认：

- `.env` 没有提交。
- 产品 AI Provider 环境变量正确配置，或明确处于 mock 开发模式。
- 数据库迁移已执行。
- Redis 可用。
- Worker 可用。
- 对象存储可用。
- 管理员账号已创建。
- 默认套餐已 seed。
- 错误监控已启用或有替代方案。
