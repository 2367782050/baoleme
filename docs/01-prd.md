# PRD：自媒体爆款智能创作系统

## 1. 产品定位

本产品服务自媒体运营者、公众号写作者、矩阵号团队和内容工作室，提供从“找选题、看爆款、生成提示词、AI 写作、排版、入草稿、会员管理、推广返佣”的一站式工作台。

产品不是营销官网，而是一个登录后即用的内容生产工具。首页只承担产品入口和价值说明，核心体验在工作台。

## 2. 目标用户

- 个人公众号创作者：需要快速找选题、写文章、排版发布。
- 内容工作室：需要管理多个赛道、多个公众号、批量生产内容。
- 矩阵运营团队：关注素材库、榜单、批量草稿、会员配额和协作效率。
- 推广代理：通过邀请码邀请用户购买会员，获取佣金。

## 3. 核心目标

首版必须让用户完成以下闭环：

1. 注册/登录。
2. 查看爆款素材或榜单。
3. 收藏或引用素材。
4. 生成提示词。
5. 使用提示词和素材生成文章。
6. 在一键排版中编辑并复制 HTML。
7. 通过会员配额限制高价值能力。

## 5. 功能需求

### 5.1 登录注册

用户可以：

- 使用邮箱、用户名、密码注册。
- 输入邀请码完成归因。
- 登录后查看会员状态和剩余配额。
- 首次注册默认获得体验会员或免费会员，具体规则由配置控制。

系统必须：

- 校验用户名、邮箱、密码。
- 防止重复邮箱和重复用户名。
- 记录邀请人。
- 生成用户默认推广码。

### 5.2 爆款素材

用户可以：

- 查看公众号榜单、热搜榜、精品对标号、文章素材。
- 按平台、赛道、行业、关键词、时间、阅读量、点赞量筛选。
- 收藏账号或文章。
- 导出榜单或文章列表。
- 从素材发起智能创作。

首版数据来源：

- 使用种子数据、CSV/Excel 导入或供应商 API 适配。
- 不默认自建爬虫。

### 5.3 提示词库

用户可以：

- 创建提示词分组。
- 手动创建、编辑、删除提示词。
- 用参考 URL 或文本素材生成提示词。
- 按赛道、作者人设、目标用户、标题结构、字数偏好生成提示词。

系统必须：

- 将提示词生成作为异步或短任务处理。
- 保存生成结果和失败原因。
- 对生成次数做会员配额限制。

### 5.4 智能创作

用户可以：

- 输入标题。
- 选择提示词。
- 选择分组。
- 添加参考 URL 或素材文本。
- 选择图片数量和图片来源策略。
- 提交文章生成任务。
- 查看任务状态、失败原因和生成结果。
- 编辑文章、删除文章、进入排版。

系统必须：

- 使用异步任务。
- 支持 pending、running、completed、failed 状态。
- 记录 AI Provider 请求、耗时、token 用量和错误。
- 对每日生成次数做会员配额限制。

### 5.5 一键排版

用户可以：

- 编辑 Markdown。
- 预览公众号风格 HTML。
- 设置标题、封面、主题模板、颜色、字体、字号、行距、段距、图片圆角。
- 复制 HTML 到剪贴板。
- 保存文章。
- 后续接入公众号草稿箱推送。

系统必须：

- Markdown 到 HTML 的转换稳定。
- 输出 HTML 应兼容微信公众号编辑器。
- 保存排版配置。

### 5.6 公众号管理

用户可以：

- 查看已授权公众号。
- 创建公众号分组。
- 删除或编辑 mock 授权账号。
- 从文章页选择公众号并发起草稿推送。

首版：

- 实现 `WeChatDraftAdapter` mock。
- 保留真实微信开放平台接入接口。

### 5.7 会员与配额

用户可以：

- 查看套餐。
- 查看当前会员。
- 查看剩余配额。
- 使用会员码兑换。
- 查看订单。

系统必须：

- 按套餐限制提示词生成、文章生成、导出、图片上传、公众号数量。
- 在高价值操作前检查配额。
- 操作成功后扣减配额。

### 5.8 推广返佣

用户可以：

- 查看推广链接和邀请码。
- 查看邀请用户。
- 查看佣金记录。
- 发起提现申请。

首版：

- 佣金自动计算。
- 提现只记录申请和审核状态，不自动打款。

### 5.9 后台运营

管理员可以：

- 导入素材数据。
- 管理用户。
- 手动开通会员。
- 审核订单和会员码。
- 审核佣金提现。
- 查看 AI 任务和失败日志。

## 6. 非功能需求

- 所有核心接口必须鉴权。
- 管理员接口必须 RBAC。
- AI 任务必须可重试。
- 所有高成本操作必须有配额检查。
- 重要行为必须记录审计日志。
- 页面必须支持桌面端和移动端。
- 失败信息必须可读，不允许只显示 unknown error。

## 7. MVP 优先级

P0：

- 登录注册
- 会员配额
- 素材列表和导入
- 提示词库
- AIProvider 文章生成
- 一键排版

P1：

- 公众号 mock 推送
- 推广返佣
- 后台运营
- Excel 导出

P2：

- 真实公众号授权
- 真实支付
- 供应商素材 API
- 自动提现
- 团队协作
