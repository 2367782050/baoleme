# Phase 14A — 试用指南

## 试用入口

| 项目 | 值 |
|------|-----|
| 本地地址 | `http://localhost:3000` |
| 管理员账号 | `admin` / `admin123` |
| 普通用户 | 通过 `/register` 注册页创建（dev 模式验证码会显示在页面上） |

## 推荐体验路径

### 1. 首页 → 注册/登录
打开 `http://localhost:3000`，看到产品首页。
点击"开始创作"或右上角"注册"，填写注册表单。

**注册步骤：**
1. 输入用户名（4-20 位）、邮箱、密码（8 位以上）
2. 点击"发送验证码"
3. dev 模式下页面会显示验证码（如 "验证码已发送（开发模式: 123456）"）
4. 输入验证码，提交注册
5. 自动跳转到工作台

### 2. 工作台
登录后进入 `/dashboard`，可以看到：
- 欢迎语（"你好，xxx"）
- 当前会员套餐和配额摘要
- 功能入口卡片：爆款素材、提示词库、智能创作、一键排版、公众号、会员中心、推广中心

### 3. 爆款素材（/materials）
5 个 Tab：
- **公众号榜单**：表格展示种子数据（财经早餐、投资人说等），含排名/行业/头像/阅读量/点赞数/原创指数
- **精品对标号**：同公众号榜单结构
- **热搜榜**：平台筛选 + 卡片展示
- **文章素材**：文章列表
- **如何找对标**：5 步教程卡片

**可操作：**
- 点击"收藏"按钮收藏账号
- 点击"导出 CSV"下载数据
- 点击"引用创作"跳转到智能创作

### 4. 提示词库（/prompts）
左侧分组侧栏，右侧提示词列表。

**可操作：**
1. 点击"+ 新建"创建分组
2. 点击"生成提示词"打开表单
3. 填写名称和领域信息
4. 点击"开始生成"——系统会异步生成提示词（Mock AI）
5. 生成完成后提示词出现在列表中

### 5. 智能创作（/writing）
文章列表 + 状态筛选 + 新建创作表单。

**可操作：**
1. 点击"开始创作"打开表单
2. 填写标题
3. 可选择分组、提示词、来源 URL、参考 URL、文本素材
4. 点击"开始生成"——系统异步生成文章（Mock AI）
5. 轮询显示任务状态（生成中 → 已生成 / 生成失败）
6. 生成完成后文章出现在列表中，点击"排版"进入一键排版

### 6. 一键排版（/formatter）
三栏布局：样式设置 | Markdown 编辑 | 预览。

**可操作：**
1. 在 Markdown 区域输入/编辑内容
2. 左侧选择模板（10 种风格）、主题色、字体、字号、行距、段距、边距、圆角
3. 点击"预览"在右侧查看渲染效果
4. 点击"复制 HTML"将渲染结果复制到剪贴板

### 7. 公众号管理（/official-accounts）
页面顶部有 amber 色提示："微信开放平台未配置，当前为模拟授权模式"。

**可操作：**
- 输入名称 → 创建 mock 公众号
- 列表显示名称/appid/状态（模拟授权）
- 点击"删除"撤销公众号

**⚠️ 当前不是真实微信授权。** 公众号创建和推送均为 mock，不会真的推送到微信。

### 8. 会员中心（/membership）
四个区域：我的会员、配额使用、会员套餐、我的订单、会员码兑换。

**可操作：**
1. 查看当前会员和配额
2. 点击套餐卡下方的"开通"创建 mock 订单
3. 弹窗提示"订单已创建，请模拟支付"
4. 订单列表中出现"模拟支付"按钮
5. 点击"模拟支付"——页面刷新，会员状态更新

**会员码兑换：**
- 输入 `TESTVIP2026` → 兑换专业版

**⚠️ 支付为 mock，不会真实扣款。**

### 9. 推广中心（/referral）
三个 Tab：邀请用户、佣金记录、提现记录。

**可操作：**
- 查看邀请码和邀请人数
- 查看佣金记录
- 提现记录中包含提现表单（支付宝姓名、账号、金额）

**⚠️ 提现为 mock，审核通过仅改状态，不真实打款。**

### 10. 后台运营（/admin）
仅管理员（admin）可访问。6 个 Tab：

- **概览**：数据卡片（用户数/订单数/待审提现/任务数）
- **用户管理**：搜索 + 表格 → 禁用/启用用户、开通会员
- **会员管理**：生成会员码
- **订单管理**：订单列表
- **提现审核**：待审提现 → 通过/驳回
- **AI 任务**：提示词任务 + 文章任务列表（含失败原因）

## Mock 边界说明

| 服务 | 当前实现 | 说明 |
|------|---------|------|
| AI | MockAIProvider | 返回固定中文内容；可通过环境变量配置真实 Provider |
| 支付 | MockBillingAdapter | 订单号 MOCK_，不真实扣款 |
| 公众号 | MockWeChatDraftAdapter | 状态 mock_authorized，不真实推送微信 |
| 提现 | mock 审核 | 审核仅改状态，不真实打款 |
| 邮箱验证 | dev 模式 API 返回 code | 页面显示"开发模式: XXXXXX" |
| 素材数据 | seed/import | 数据库导入，不是实时抓取 |

## 已知限制

- **数据库**：Prisma dev 本地 PostgreSQL 可能不稳定，推荐 Docker Postgres（`docker compose up -d`）
- **队列**：当前使用 `setImmediate`（进程内执行），生产环境建议替换为 BullMQ + Redis
- **AI**：默认 MockAIProvider 不产生真实内容，需通过 `AI_*` 环境变量配置真实 AI Provider
- **支付/公众号/提现**：全部 mock，接真实服务需要商户资质和密钥
- **UI**：当前为 MVP 风格，后续可持续打磨
