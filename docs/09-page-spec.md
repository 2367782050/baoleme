# 页面级规格

本文档用于约束前端页面，不规定最终视觉风格。整体 UI 应为扁平化、工具型、信息密度适中，避免营销站式大面积装饰。

## 1. 公共布局

### 1.1 顶部导航

登录前：

- Logo/产品名。
- 爆款素材。
- 提示词库。
- 智能创作。
- 一键排版。
- 使用教程。
- 登录。
- 注册。

登录后：

- 爆款素材。
- 提示词库。
- 智能创作。
- 一键排版。
- 公众号。
- 会员。
- 推广。
- 后台，管理员可见。
- 用户菜单。

用户菜单包含：

- 用户名。
- 当前会员。
- 配额摘要。
- 退出登录。

### 1.2 通用状态

每个列表页面必须有：

- 加载态。
- 空状态。
- 错误态。
- 分页。
- 搜索或筛选后无结果状态。

## 2. 首页

目标：

- 说明产品价值。
- 引导注册/登录。
- 展示核心功能入口。

首屏内容：

- 产品名。
- 一句话定位：自媒体爆款智能创作工作台。
- 主按钮：开始创作。
- 次按钮：查看素材库。

功能区：

- 爆款素材。
- 提示词库。
- 智能创作。
- 一键排版。
- 公众号草稿。
- 会员配额。

禁止：

- 不要使用参考站点 Logo。
- 不要复制参考站点完整文案。
- 不要把首页做得比工作台更复杂。

## 3. 登录页

字段：

- 账号，用户名或邮箱。
- 密码。

操作：

- 登录。
- 去注册。
- 忘记密码，P2。

错误：

- 账号不存在。
- 密码错误。
- 账号禁用。

## 4. 注册页

字段：

- 用户名。
- 邮箱。
- 邮箱验证码。
- 密码。
- 邀请码，可选。
- 同意协议勾选。

操作：

- 发送验证码。
- 注册。
- 去登录。

规则：

- 用户名 4 到 20 位。
- 密码至少 8 位。
- 邮箱格式必须正确。
- 验证码过期后不可用。

## 5. 爆款素材页

顶部：

- 页面标题。
- 今日剩余导出次数。
- 导入素材按钮，管理员可见。

标签：

- 公众号榜单。
- 精品对标号。
- 热搜榜。
- 文章素材。
- 如何找对标。

筛选：

- 平台。
- 行业。
- 关键词。
- 时间范围。
- 排序字段。

公众号榜单表格列：

- 排名。
- 行业。
- 头像。
- 账号名称。
- 头条平均阅读。
- 平均阅读。
- 日发文数。
- 总点赞数。
- 原创指数。
- 操作。

操作：

- 收藏。
- 查看素材。
- 引用创作。
- 导出。

## 6. 提示词库页

顶部：

- 页面标题。
- 生成提示词按钮。
- 本月剩余生成次数。

左侧或顶部：

- 分组列表。
- 新建分组。

主区域：

- 提示词卡片或表格。
- 搜索。
- 编辑。
- 删除。

生成提示词表单：

- 素材类型：URL/文本。
- URL 列表，最多 7 个。
- 文本素材。
- 分组。
- 提示词名称。
- 作者人设。
- 性格特征。
- 内容领域。
- 目标受众。
- 标题结构。
- 目标字数。
- 降低 AI 痕迹开关。

提交后：

- 展示任务状态。
- 成功后保存到提示词库。

## 7. 智能创作页

顶部：

- 页面标题。
- 开始创作按钮。
- 今日已生成/可生成次数。

筛选：

- 全部。
- 生成中。
- 已生成。
- 生成失败。
- 未推送。
- 已推送。
- 分组。

文章列表字段：

- 封面。
- 标题。
- 提示词。
- 分组。
- 生成状态。
- 推送状态。
- 更新时间。
- 操作。

操作：

- 查看。
- 编辑。
- 进入排版。
- 推送草稿。
- 删除。

开始创作表单：

- 标题。
- 分组。
- 提示词。
- 来源 URL。
- 参考 URL。
- 文本素材。
- 图片数量。
- 图片策略。
- 是否需要素材。

## 8. 一键排版页

整体结构：

- 顶部工具栏。
- 左侧编辑区。
- 右侧预览区。
- 设置面板，可在侧栏或顶部。

工具栏：

- 标题输入。
- 设置封面。
- 保存。
- 复制 HTML。
- 推送草稿。

编辑区：

- Markdown 编辑器。

预览区：

- 公众号文章预览。

设置：

- 模板。
- 主题色。
- 字体。
- 字号。
- 行距。
- 段距。
- 两侧边距。
- 图片圆角。
- 降低 AI 痕迹开关。

模板建议：

- 青绿导读风。
- 留白清新风。
- 蓝色专栏风。
- 紫色胶囊风。
- 渐变醒目风。
- 轻卡片风。
- 杂志双线风。
- 科技清爽风。
- 橙色暖调风。
- 黑白编辑风。

## 9. 公众号管理页

顶部：

- 页面标题。
- 授权公众号按钮。
- 当前可绑定数量。

列表：

- 头像。
- 名称。
- appid。
- 授权状态。
- 分组。
- 操作。

首版操作：

- 创建 mock 公众号。
- 编辑分组。
- 删除。

真实授权未配置时：

- 明确提示“微信开放平台未配置，当前为模拟授权模式”。

## 10. 会员中心页

标签：

- 会员套餐。
- 我的会员。
- 我的订单。
- 会员码兑换。

套餐卡：

- 名称。
- 价格。
- 原价。
- 有效期。
- 权益列表。
- 开通按钮。

我的会员：

- 当前套餐。
- 到期时间。
- 配额使用情况。

订单：

- 订单号。
- 套餐。
- 金额。
- 状态。
- 创建时间。

首版：

- 支持 mock 支付。
- 支持会员码兑换。

## 11. 推广中心页

顶部：

- 推广链接。
- 邀请码。
- 二维码。
- 复制按钮。

数据卡：

- 邀请人数。
- 累计订单。
- 累计佣金。
- 可提现金额。
- 当前佣金比例。

标签：

- 邀请用户。
- 佣金记录。
- 提现记录。

提现表单：

- 支付宝姓名。
- 支付宝账号。
- 提现金额。
- 备注。

## 12. 后台运营页

导航：

- 数据概览。
- 用户管理。
- 会员管理。
- 素材导入。
- AI 任务。
- 订单管理。
- 提现审核。
- 系统配置。

后台要求：

- 管理员鉴权。
- 审计日志。
- 危险操作二次确认。
- 导入任务展示行级错误。

## 13. 移动端要求

必须可用：

- 登录注册。
- 查看素材。
- 生成提示词。
- 生成文章。
- 排版预览。

移动端可降级：

- 大表格改为卡片列表。
- 后台运营可只保证基础可访问。
- 一键排版可上下布局。
