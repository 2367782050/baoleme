# 参考站点拆解

## 1. 参考对象

参考网站：`https://baolem.com/`

本项目只参考功能路径和信息架构，不复制其代码、图片、品牌、Logo、文案和私有数据。

## 2. 总体判断

参考站点是一个以微信公众号内容生产为核心的工具系统，重点不是传统营销页，而是登录后的工作台：

- 找爆款素材。
- 生成提示词。
- 生成文章。
- 在线排版。
- 推送公众号草稿。
- 用会员套餐控制权限和配额。
- 用推广返佣做增长。

## 3. 页面结构

公开首页包含：

- 产品定位：自媒体爆款智能创作系统。
- 功能入口：爆款素材、提示词库、智能创作、一键排版、公众号、教程。
- 功能说明：AI 创作、素材榜单、排版、文章库、提示词库、草稿箱。
- 登录注册入口。

登录后核心页面：

- 爆款素材
- 提示词库
- 智能创作
- 一键排版
- 公众号管理
- 会员中心
- 推广中心
- 使用教程

## 4. 爆款素材拆解

参考站点的素材模块包含：

- 精品对标号。
- 公众号榜单。
- 热搜榜。
- 如何找对标的教程。

公众号榜单字段包括：

- 排名
- 行业
- 头像
- 公众号名称
- 头条平均阅读
- 平均阅读
- 日发文数
- 总点赞数
- 原创指数
- 操作

行业分类包括：

- 综合
- 国际
- 体育
- 娱乐
- 社会
- 财经
- 科技
- 情感
- 汽车
- 教育
- 时尚
- 游戏
- 军事
- 旅游
- 美食
- 文化
- 健康养生
- 搞笑
- 家居
- 动漫
- 宠物
- 母婴育儿
- 星座运势
- 历史
- 音乐

数据来源判断：

- 这些字段更像第三方公众号数据平台或已有数据仓库。
- 与公开公众号榜单平台常见字段高度相似。
- 不像直接实时抓微信后台。
- 因此本项目将素材数据做成 `MaterialProvider`，首版用导入/种子库，后续再接供应商。

## 5. 提示词库拆解

提示词库能力：

- 分组管理。
- 列表筛选。
- 创建、编辑、删除提示词。
- 生成提示词。

提示词生成参数：

- 素材类型：URL 或文本。
- 参考 URL：1 到 7 个。
- 文本素材：最大约 20000 字。
- 作者人设。
- 性格特征。
- 内容领域。
- 目标受众。
- 标题结构。
- 字数偏好。
- AI 痕迹规避开关。

首版应完整实现这些字段，但不需要照搬参考站点的具体 UI。

## 6. 智能创作拆解

智能创作能力：

- 按分组查看文章。
- 状态筛选：生成中、已生成、生成失败、未存稿、已存稿。
- 开始创作。
- 查看、编辑、删除文章。
- 批量操作。
- 存入草稿箱。

文章生成参数：

- 标题。
- 参考 URL。
- 文本素材。
- 提示词。
- 分组。
- 图片数量。
- 是否需要素材。
- 是否使用原文图片。

任务行为：

- 文章生成是异步任务。
- 前端定时轮询状态。
- 失败后展示失败原因。

## 7. 一键排版拆解

一键排版能力：

- 标题编辑。
- 封面设置。
- Markdown 编辑。
- HTML 预览。
- 模板样式选择。
- 主题色选择。
- 字体、字号、行高、段距、边距设置。
- 图片圆角。
- AI 检测规避/朱雀检测相关开关。
- 复制 HTML。
- 存入公众号草稿箱。

首版重点：

- 保证 Markdown 到公众号 HTML 的输出质量。
- 保证复制到微信公众号编辑器可用。

## 8. 会员中心拆解

参考站点套餐包含：

- 基础月卡。
- 专业月卡。
- 专业季卡。
- 尊享年卡。
- 体验卡。

会员权益维度：

- 提示词生成次数。
- AI 文章生成次数。
- 草稿箱推送次数。
- 图片上传次数。
- 可绑定公众号数量。
- 导出次数。

首版应实现：

- 套餐配置表。
- 当前会员状态。
- 配额检查。
- 配额扣减。
- 会员码兑换。
- mock 订单。

## 9. 推广中心拆解

推广中心能力：

- 推广链接。
- 推广二维码。
- 推广等级。
- 佣金比例。
- 累计 GMV。
- 可提现余额。
- 邀请用户。
- 佣金记录。
- 提现记录。

首版实现：

- 邀请码归因。
- 订单完成后生成佣金。
- 提现申请。
- 后台审核。

## 10. 结论

本产品的实现难点不在页面数量，而在业务闭环：

- 素材数据从哪里来。
- AI 生成如何稳定。
- 会员配额如何贯穿所有高价值功能。
- 公众号和支付如何通过适配层逐步接真实服务。

因此开发必须优先建立清晰的领域模型和服务接口，再做页面。
